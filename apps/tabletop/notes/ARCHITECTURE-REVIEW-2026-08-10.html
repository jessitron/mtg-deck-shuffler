Problem: five unrelated concerns share one ShapeUtil interface, each with its own tldraw-internals workaround, so no single function tells you how a card behaves.

Solution: pull tap/zone/passenger rules into a plain CardPhysics module the ShapeUtil calls into; the ShapeUtil becomes a mechanical translator of tldraw hook signatures.

  • locality: tap/zone/passenger rules testable without a live editor
  • leverage: one physics interface, hooks stay mechanical
  • interface shrinks; implementation absorbs the tldraw workarounds

Problem: "a card arrives" bounces across four files, and the builder module's interface still exposes tldraw's record shape (typeName, parentId, meta, three as any casts) instead of hiding it.

Solution: a shape-record constructor that takes only domain values (position, image, owner, sleeve) and never leaks the tldraw fields to callers.

  • leverage: one place lists every required prop
  • seam: callers stop needing to know tldraw's record shape
  • deletion test: inlining today would visibly duplicate six fields at ~4 call sites — the module already has real depth, just a leaky interface

Problem: the hook that causes a gesture already knows its name; a separate listener re-derives the same fact from a raw prop diff, so every new gesture needs a matching branch in two places.

Solution: have onClick/onTranslateEnd/onDragShapesIn emit their own named events; keep the store-diff listener only for the generic fallback.

  • locality: gesture knowledge lives once, where it's computed
  • a detach-reported-as-attach bug already came from this duplication
  • deletion test: collapsing the two doesn't move complexity anywhere — it removes a duplicate

Top recommendation

Split MtgCardShapeUtil's tldraw-interop from its card physics

Hottest file in the ship (21 commits) and the only candidate with genuine depth trapped behind a fused interface — every other candidate here (2, 4, 6) is a satellite of the same file or the same "physics leaks into an adapter" pattern. Deepening this one first gives the others a place to land.

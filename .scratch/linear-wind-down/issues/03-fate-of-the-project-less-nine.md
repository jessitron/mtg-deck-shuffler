Mountain: safe-harbor

Status: needs-triage

## Question

Archiving the "MTG Deck Shuffler" project does nothing to the 9 Tabletop issues that have
**no Linear project** (JES-144…JES-154, filed 2026-08-01 from the old
`apps/tabletop/notes/todo.md`). What happens to them, so that "nothing lives in Linear
anymore" is actually true?

HITL. The options aren't equivalent:

- **Cancel each one** — they leave the team's active views but stay readable in Linear.
- **Move them into the project first, then archive** — one bulk edit, and archiving sweeps
  them with everything else.
- **Archive each issue individually** — strongest, most clicks.
- **Leave them** — accept that the team backlog keeps showing 9 orphans forever.

Also worth settling here, because it generalises: when an issue is *kept* (migrated to
`TODO.md`), does it still get closed out in Linear, or is archiving the project enough?
Whatever's decided for the 9 should be the same rule for all 40.

The answer names the disposal action, whether it applies to kept and killed issues alike,
and whether it needs a script or is hand-work in the Linear UI.

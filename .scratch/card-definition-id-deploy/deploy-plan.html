1
Make sure main is green and nobody is at a table

2
Deploy the fleet
./deploy.sh               # Spine → Shuffler → Tabletop, stops on first failure
3
Wipe the databases Spine: do it Shuffler: optional
Spine's log holds v1 events nothing can read now. The Shuffler cleans itself up; wipe it only for a fresh start.
kubectl exec deploy/spine -- sh -c 'rm -f /data/spine.db /data/spine.db-wal /data/spine.db-shm'
kubectl rollout restart deploy/spine

# optional
kubectl exec deploy/mtg-deck-shuffler -- sh -c 'rm -f /data/data.db /data/data.db-wal /data/data.db-shm'
kubectl rollout restart deploy/mtg-deck-shuffler
4
Smoke test
  • load a precon, start a game, cards show images
  • join a table, commander lands on the Tabletop
  • play a card to the table → it appears
  • drag it back off the table → Shuffler gets it
  • flip a two-faced card

Check Honeycomb env: mtg-deck-shuffler
